Penjelasan:
1. Start: Program dimulai
   
   Menu login: Sistem menampilkan menu login dan meminta pengguna untuk menginput username dan password.
2. Proses Login: Sistem mengecek apakah login sebagai admin atau sebagai mahasiswa. Jika username atau password salah maka        login gagal dan meminta menginput ulang. jika berhasil maka akann menampilkan 'login berhasil' dan role. 
3. Tampilkan Menu 1-5: 1. daftar pasien baru, 2. ubah pasien, 3. hapus pasien, 4. lihat pasien, dan 5. logout
4. Menu 1(daftar pasien baru)
   Pada menu 1, role user dan admin sama-sama bisa menambah pasien baru dengan menginput nama, umur dan keluhannya, lalu          sistem akan menentukan poli. Jika keluhan pasien adalah 'gigi', maka akan masuk ke Poli Gigi. Jika keluhan bukan gigi, maka    sistem akan mengecek umur pasien, dimana jika umur pasien kurang dari 17 tahun, maka akan masuk ke Poli Anak. Jika keluhan     bukan 'gigi' dan umur lebih dari 17 tahun, maka akan masuk ke Poli Umum.
   Setelah selesai, sistem akan menyimpan data di dalam list dan akan menampilkan output bahwa pendaftaran berhasil.
